# Подготовка BoxGirl для Live2D Cubism

## 1. Исходник

Рисовать на прозрачном холсте 4096×4096. Минимальная высота персонажа в PSD — около 3600 px. Все скрытые области головы, шеи, корпуса и рук дорисовать с запасом.

Обязательные группы слоёв:

- задние, боковые и передние волосы; крупные пряди отдельно;
- лицо, уши, шея, нос и тени;
- белок, радужка, зрачок, блик, веки и ресницы каждого глаза;
- отдельные брови;
- внутренняя часть рта, зубы, язык, губы и уголки;
- торс, капюшон, перед худи, складки и тени;
- плечи, рукава, предплечья и кисти;
- отдельные шнурки худи;
- три позы рук: спокойная, объяснение открытой ладонью, приветствие.

Перед импортом убрать пустые слои, сохранить уникальные имена и не объединять детали, которые должны двигаться независимо.

## 2. Параметры

Создать стандартные `ParamAngleX/Y/Z`, `ParamBodyAngleX/Y/Z`, `ParamEyeLOpen/ROpen`, `ParamEyeBallX/Y`, параметры бровей, `ParamMouthOpenY`, `ParamMouthForm`, `ParamBreath` и пользовательские параметры рук.

Для lip sync подготовить как минимум закрытый рот и формы A/I/U/E/O. В простом режиме приложение управляет `ParamMouthOpenY`; MotionSync использует `.motionsync3.json`.

## 3. Physics и motions

- Волосы: несколько цепочек с малой/средней амплитудой.
- Шнурки: независимые цепочки с ограниченным углом.
- Рукава и капюшон: только мягкая вторичная реакция.
- Не привязывать рот к body motion: lip sync должен иметь последний приоритет.
- One-shot motions должны завершаться в позе, из которой возможен плавный возврат в idle.

Семантические имена, пути и fade-параметры описаны в `public/avatar/model.manifest.json`. При отсутствии файла runtime обязан использовать `neutral` или `none`.

## 4. Экспорт

Положить экспорт в `public/live2d/Resources/BoxGirl/`:

```text
BoxGirl.model3.json
BoxGirl.moc3
BoxGirl.physics3.json
BoxGirl.pose3.json              # если используется
BoxGirl.motionsync3.json        # если используется
textures/
expressions/
motions/
```

Cubism Core разместить в `public/live2d/Core/` в соответствии с официальной структурой SDK. Обе папки исключены из Git, потому что Core и авторские ассеты имеют отдельные условия распространения.

## 5. Порядок расчёта кадра

1. idle/base pose;
2. gesture motion;
3. expression;
4. breath, blink, gaze и physics;
5. lip sync;
6. ограничение диапазонов параметров.

Сначала проверить каждый слой отдельно, затем сочетания `speaking + expression + gesture` и отмену motion новым `turnId`.
